# 织法·回响纺锤 (Weaver Echo Memory)

这是为 [SillyTavern](https://github.com/SillyTavern/SillyTavern) 开发的第三方扩展插件，专门适配「织法者4.0【liteC4】」预设。
它能够自动读取 AI 回复中的 `<VEC_ARCHIVE>` 归档指令，自动存取和检索长期记忆，让 AI 能够“回想起”之前的细节。

当前版本：**v1.2.0 安心使用版**。

## 📦 安装方法

### 方式一：GitHub 链接安装（推荐）
1. 打开 SillyTavern，进入 **扩展** 面板（顶部的魔方图标）
2. 展开 **安装扩展** 菜单
3. 在文本框中粘贴本插件的 GitHub 仓库地址
4. 点击安装并重启 SillyTavern

### 方式二：手动 ZIP 安装（无法访问 GitHub 的用户）
1. 下载本仓库的 `weaver-vec-memory.zip` 压缩包
2. 解压得到 `weaver-vec-memory` 文件夹
3. 将整个文件夹复制到你的 SillyTavern 安装目录下的：
   `public/scripts/extensions/third-party/`
4. 重启 SillyTavern
5. 在扩展面板中确认已勾选启用

## ⚙️ 核心功能与配置

安装完成后，在扩展面板最底部找到 **织法·回响纺锤** 设置抽屉。

### 1. 两种检索模式
- **关键词匹配（默认推荐）**：无需下载任何模型，无需配置 API，即装即用。完全本地执行，速度极快。
- **混合检索（关键词 + 语义向量）**：支持对接硅基流动（SiliconFlow）等兼容 Embedding 格式的外部向量 API，实现更高级的语义相似度检索。

### 2. 自动化机制
扩展会自动监听 AI 的回复。当 AI 按照预设在回复中输出 `<VEC_ARCHIVE>` 与 `[VEC]` 标签时，扩展会自动截获并保存到本地记忆库。

### 3. v1.2.0 安心使用功能
- **最近一次召回预览**：查看上一轮实际注入给模型的回响记忆。
- **暂停下一轮回响**：下一次生成时不注入记忆，生成后自动恢复；如果点错，可以再次点击取消暂停。
- **召回数量档位**：轻量 2 条、标准 4 条、深度 6 条，也可以自定义。
- **手动添加模板**：支持关系变化、物品事件、伏笔揭露、可回调细节四类常用模板。
- **危险操作自动备份**：清空、覆盖导入、重建、校准写入前自动备份，并可恢复上一次备份。
- **安全重建当前聊天自动记忆**：重建时默认保留手动添加记忆。

### 4. 大总结校准记忆

这个功能适合织法者4.0的长剧情流程：

1. 聊到 50-100 楼后进行大总结。
2. 用户手动修正大总结中的偏差。
3. 准备隐藏前文，继续只让模型看正确的大总结。
4. 使用 **大总结校准记忆**，让插件记忆库也跟着这份正确大总结对齐。

大总结楼层可以是 AI 楼、用户楼或系统式总结楼；只要该楼文本是你确认后的事实基准，就可以作为校准来源。

可选范围：
- **全文校准**：处理大总结之前所有旧自动记忆。例如第 100 楼是全文大总结，就处理 1-99 楼。
- **分段校准**：只处理指定楼层范围。例如只处理 51-99 楼。

可选方式：
- **仅清理旧自动记忆**：只删除范围内旧自动记忆，不新增。
- **用大总结生成新的校准记忆**：可以调用当前 SillyTavern 模型，也可以配置校准专用 API。专用 API 使用 OpenAI 兼容的 `/v1/chat/completions` 格式，并提供“测试校准模型”按钮，适合在当前对话模型服务不稳定时使用。

安全流程：

```text
生成校准预览
↓
用户检查将删除多少旧记忆、将新增哪些校准记忆
↓
确认写入
↓
自动备份当前记忆库
↓
删除范围内旧自动记忆并写入新校准记忆
```

新生成的记忆会标记为：`大总结校准｜第X楼`，方便和普通自动归档、手动添加区分。

## 🔧 可调参数

- **召回数量档位**：控制每次对话最多召回几条历史记忆。
- **记忆衰减率**：每轮对话后，未被提及的记忆权重下降比例。当记忆被检索命中时，权重会恢复。
- **归档重要度阈值**：过滤掉 AI 记录的低价值日常废话。
